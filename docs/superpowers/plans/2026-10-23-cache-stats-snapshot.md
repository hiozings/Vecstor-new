# 查询缓存统计常数时间快照

## 设计与边界

按用户要求优化每查询统计成本。`CachedLeaseReader.describe()` 仅需进程总量，现调用 `stats(database_id)` 在锁内扫描全缓存。新增 `VersionedVectorCache.process_snapshot()`，在同一把锁内复制已维护的标量和容器长度，返回独立字典，时间/临时空间均 O(1)。共享锁内快照构造函数供管理统计复用；查询统计字段和请求局部计数不变。显式分库管理统计和清理仍可 O(N)，不引入额外分库记账或改变缓存准入、LRU、容量及版本语义。O(1) 指持锁计算，不承诺并发等待时间固定。
