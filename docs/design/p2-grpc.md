# P2 gRPC 存算分离设计

日期：2026-10-12。沿用 P1 的字段、SQL 子集和平方 L2 语义，新增独立存储与计算进程。本阶段只读单快照，不提供在线更新、ANN、GPU 调度或多节点同步。

## 服务与数据流

客户端 → Compute.Query → Storage.GetManifest / ScanMetadata / FetchVectors。

存储进程独占读取启动参数指定的 NPZ，校验并加载为只读数据；SHA-256 文件摘要作为 snapshot_version，同一进程始终提供这一固定快照。文件字节一次读取，校验和解析使用相同字节，避免版本与数据不一致。源文件后续改变不影响已加载快照；更新需重启服务，在线版本发布留待 P4。

计算服务只配置存储地址和 RPC deadline，不接收数据文件作为查询输入；解析查询、固定清单版本、验证向量、获取合法元数据、分批拉取对应向量、穷举距离与 Top-K。存储侧允许元数据过滤下推，每次重新白名单校验原查询，仅执行生成的参数化过滤 SQL。

## 协议

唯一源文件：`proto/vecstor/rpc/services.proto`；生成 Python 文件放在 `src/vecstor/rpc/`。使用已有 grpcio-tools 编译，不手改生成文件。

| RPC | 输入 | 输出 |
| --- | --- | --- |
| GetManifest | 空请求 | 版本、行数、维度、距离度量 |
| ScanMetadata | 固定版本、混合 SQL、批次行数 | 流式批次：版本、总命中数、offset、完整元数据行；空结果也发一个批次 |
| FetchVectors | 固定版本、ID 数组 | 版本、维度、同序 ID、little-endian float32 行主序 bytes |
| Query | SQL、double 数组查询向量 | 类型化元数据行、投影列、距离、命中数、版本、维度及通信统计 |

id/timestamp 使用 int64，距离和 value 使用 double，避免 JSON 数值中转丢失大整数。结果经客户端按投影列恢复为与 P1 相同的字典结构。扫描与向量响应必须校验版本、行数、顺序、大小、有限值；不完整流或不匹配响应作为错误，不能返回部分成功结果。

批次默认 256 行，上限 1024；向量批次还受 1 MiB 目标负载限制。gRPC 单消息限制 4 MiB，超大单行/维度明确拒绝；大查询结果超过传输限制时明确失败。统计口径为 Protobuf 请求与响应序列化字节数，不包含 HTTP/2、TCP、TLS 开销，不冒充网卡实际字节数。

## 生命周期与错误

默认仅绑定 127.0.0.1。服务启动后输出 JSON ready 事件（实际地址、进程 ID、角色），SIGINT/SIGTERM 关闭服务。端口为 0 时由内核分配，测试据 ready 信息连接。

每条查询有总 deadline，计算侧向下游传播剩余时间；RPC 失败直接返回，应用层自动重试次数为 0，不会静默使用本地文件或缓存。存储读取处理取消，客户端离开流时主动取消。

非法 SQL/参数 → INVALID_ARGUMENT；未知版本 → FAILED_PRECONDITION；未知 ID → NOT_FOUND；消息/批次过大 → RESOURCE_EXHAUSTED；不可达/超时保持相应 gRPC 状态；响应不一致 → DATA_LOSS。

DuckDB 元数据连接用锁串行访问，计算侧每条请求独立 Top-K 状态。存储服务使用 8 个工作线程，扫描流以非阻塞信号量限制为最多 4 条，超额扫描返回 RESOURCE_EXHAUSTED，始终保留向量读取的执行容量，避免背压扫描占满线程。计算服务使用 4 个工作线程。该限制用于原型正确性，不宣称性能最优。未启用 TLS 和鉴权，只用于可信本地或受控实验网络。

## 隔离验收

Linux 验收工具启动独立存储进程与计算进程。计算进程在导入业务库及创建线程之前，通过 Landlock 限制其文件读取/写入权限，只允许读取解释器、依赖、项目 src/scripts 和必要系统目录；存储目录不在允许列表。限制对后续线程生效，失败时拒绝启动，不降级成无隔离运行。

限制后计算进程亲自尝试列出存储目录、读取快照，必须获得 PermissionError，输出证据，再启动 gRPC 服务。验收比对同一批 P1 查询，包含空结果、少于 K、并列和非连续 ID；停止存储进程后，原计算服务的下一条查询必须失败，以排除全量本地数据替代网络读取。

Landlock 验收依赖 Linux 内核能力；不支持的平台明确报错，不能标为隔离通过。此验证证明文件访问被内核拒绝且查询走 RPC，不宣称具备完整容器、网络或多租户安全隔离。
